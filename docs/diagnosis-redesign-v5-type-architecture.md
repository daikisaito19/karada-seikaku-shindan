## 0. 最初に: これまでの検証が間違っていた

ご指摘の「ペルソナが循環的な評価になっていないか」は、**完全に当たっていた**。

`personas.ts` の理想回答は、私が **スコアリングロジックを見ながら、そのタイプに着地するまで回答を調整して作ったもの**。「16/16 一致」はロジックの正しさではなく、私がロジックに合わせて回答を作った結果でしかなかった。テストが自分の答えを見てから採点していたのと同じ。

そこで今回、**スコアもgateも一切見ずに、タイプ説明と設問の文面だけを読んで「その人なら素直にこう答えるだろう」という回答を16タイプ分作り直した** (`blind-personas.ts`)。作成後に一度もチューニングせず、そのまま現エンジンにかけた結果:

外した6件は、いずれもご指摘の吸収関係とほぼ一致している。以下、原因を1件ずつ特定した。

### 決定的な欠陥①: 特徴を強く出すほど、そのタイプから弾かれる

01 充電下手のブラインド回答は QI(元気のなさ)=82% と極めて高いのに、充電下手のgateを通らず電池切れになった。
現在のgateが `SP >= QI - 12` という**軸同士の引き算**で01と02を分けているため、QIが高くなるほどSPに要求される水準が跳ね上がる。QI=82%なら SP>=70% が必要だが、SP軸の理論最大値は17点しかなく、消化器系の設問をほぼ全部最大で選ばないと到達できない。

軸の強さ別に「そのタイプになる確率」を実測した (N=80000):

```
充電下手 / QI(元気のなさ)
  QI 50-59%: 48.2%  →  60-69%: 43.8%  →  70-79%: 21.6%   ← 疲れているほど確率が下がる
電池切れ / QI(元気のなさ)
  QI 50-59%:  0.0%  →  60-69%: 18.2%  →  70-79%: 35.1%   ← そのぶん電池切れが吸収
```

**「疲れやすい人」と答えれば答えるほど「充電下手」から遠ざかる。** これは閾値の調整では直らない、設計そのものの欠陥。他6タイプは単調性が成立しており、この問題は01↔02のような「軸の引き算で分けているペア」に固有のもの。

### 決定的な欠陥②: 自然な回答が、他タイプの専用シグナルと衝突する

05 冷え冷えのブラインド回答は YANG(冷え)=93% と全タイプ中で最も冷えているのに、スロースタートになった。原因はQ29で「最初はイマイチだけど、慣れると普通に動ける」を選んだこと。

**冷え性の人が「日中に温まってくる」と答えるのは、この上なく自然**である。しかし現在の設計では、この選択肢はスロースタートの専用シグナル(+20点)であり、かつ冷え冷えのgateには `Q29 ≠ C` という**除外条件**が入っている。つまり冷え性の人が自分の体感を正直に答えると、冷え冷えから強制的に追い出される。

同じ衝突が12 夜型スイッチでも起きた(夜型の人が「朝はイマイチだが慣れると動ける」と答えるのも自然)。

### 決定的な欠陥③: 「〜でないこと」で定義されたタイプには、決定打の設問が存在しない

設問ごとに「その選択肢を選ぶと、どのタイプになる確率がどれだけ上がるか」を実測した (N=60000)。各タイプの最大の決定打は:

| タイプ | 決定打の設問 | 押し上げ幅 |
|---|---|---|
| 食後スリープ | Q2=C | +25.1pt |
| スロースタート | Q29=C | +16.5pt |
| うるおい不足 | Q28=D | +12.4pt |
| カラダ渋滞 | Q3=B | +11.3pt |
| 夜型スイッチ | Q16=B | +9.3pt |
| 頭ぐるぐる | Q24=D | +8.8pt |
| 常時アクセル | Q22=A | +6.9pt |
| **イライラ充満** | Q9=B | **+1.8pt** |
| **電池切れ** | Q10=B | **+1.3pt** |

イライラ充満と電池切れだけ、決定打が存在しない。理由は明確で、この2つだけが **肯定的な条件ではなく「〜でないこと」で定義されている**から:

- イライラ充満 = `ST高` かつ `STAが低い` かつ (渋滞でも思考型でも行動型でもない)
- 電池切れ = `QI高` かつ `SPがQIより低い`

**「これを選べばこのタイプになる」という設問が1つも無いタイプは、ユーザーから見れば存在しないのと同じ。** ランダム回答での出現率(0.9%/0.6%)が低いのは分布の偏りではなく、この構造の帰結。

### 決定的な欠陥④: クセ強ミックスは、名前と実装が逆

「クセ強ミックス」という名前を素直に読めば「尖った特徴を何個も同時に持っている人」である。そう解釈してブラインド回答を作ったところ(寒がりなのにほてる、こりもむくみも乾燥もある)、**7つのタイプのgateを同時に通過し**、うるおい不足に判定された。

一方、実装上のクセ強ミックスは `どのgateも通過しなかった人` = 特徴が何も立っていない人。**名前が意味することと、実装が拾っている人が正反対**になっている。

さらに v4 検証では、実際にクセ強ミックスに落ちた人の **94.8%が、いずれかのタイプの軸条件まで5pt以内**だった。つまり実態は「多面的な人」でも「特徴が無い人」でもなく、「惜しいところで専用シグナルに該当しなかった人」の受け皿になっている。

### この4つから導かれる結論

閾値の微調整では直らない。**「8軸を組み合わせて16タイプを作る」という構造そのもの**が原因である。

8軸(東洋医学の証)は本来、互いに排他的ではない。気虚と血虚は同時に起きるし、陰虚と血虚はどちらも「乾き」として現れる。**重なることが前提の軸を、重なってはいけない16タイプに直接マッピングしている**ため、タイプ同士が必然的に食い合う。その食い合いを止めるために「〜でないこと」「軸の引き算」「他タイプの除外条件」を足していった結果が、上記①〜④である。

以下、構造から作り直す案を示す。

## 1. 16タイプ再定義 — 4つの系統に整理する

ご提示のグループ分けでは「ほてほて」が水分系と温度系の両方に入っていた。これはまさに上記の重なりの表れなので、**ほてほて=熱(温度系)、うるおい不足=乾き(水分系)** と切り分けて整理した。

| 系統 | タイプ | 系統の意味 |
|---|---|---|
| **エネルギー系** (4) | 01 充電下手 / 02 電池切れ / 13 スロースタート / 10 めぐり不足 | 使える元気の量とタイミングの問題 |
| **ストレス系** (4) | 07 カラダ渋滞 / 08 イライラ充満 / 11 頭ぐるぐる / 14 常時アクセル | ストレスがどこに出るかの問題 |
| **めぐり・水分系** (3) | 03 食後スリープ / 04 むくみストック / 09 うるおい不足 | 水分と消化の、溜まる/足りないの問題 |
| **温度・リズム系** (3) | 05 冷え冷え / 06 ほてほて / 12 夜型スイッチ | 体温と一日のリズムの問題 |
| **複合** (2) | 15 波乗りコンディション / 16 クセ強ミックス | 系統が1つに決まらない状態 |

重要なのは、**同じ系統の中のタイプ同士は「程度」ではなく「種類」で分かれる**こと。エネルギー系の4つは「どれくらい疲れているか」では分けない(これが①の失敗)。「疲れがいつ・どう出るか」という別の種類で分ける。

## 2. 各タイプの核

各タイプの「核となる体感 / 日常行動 / ストレス時 / 疲れ方 / 回復 / 決定的な違い」。

### エネルギー系

**01 🔋 充電下手**
- 核: 動けるし頑張れる。でも休んでも戻りきらない。充電ケーブルが断線している感じ。
- 日常: 予定は普通にこなす。休みの日は寝て終わるが、それでも回復しない。
- ストレス時: 無理してでも動こうとする。
- 決定的な違い: 02と違い「出力は出せる」。13と違い「朝だけの問題ではない」。

**02 🪫 電池切れ**
- 核: そもそも残量が少ない。動き出す前から足りていない。
- 日常: 少し動くと息切れ。予定を入れること自体がしんどい。
- ストレス時: 何もできなくなる、逃げたくなる。
- 決定的な違い: 01と違い「頑張るという選択肢が無い」。13と違い「時間が経っても回復しない」。

**13 🐢 スロースタート**
- 核: 起動が遅いだけ。動き出せば普通に動ける。
- 日常: 朝が重い。午前中は使い物にならないが、午後は平気。
- 決定的な違い: 01/02と違い「エンジンがかかった後は問題ない」。12と違い「夜に元気なわけではない」。

**10 🩸 めぐり不足**
- 核: 量ではなく供給の問題。血色・ふらつき・爪や髪に出る。
- 日常: 立ちくらみ、顔色が悪いと言われる、冷えと乾燥が同居。
- 決定的な違い: 01/02と違い「疲れよりも、届いていない感じ」。09と違い「乾燥だけでなくふらつきがある」。

### ストレス系

**07 🚦 カラダ渋滞** — ストレスが **体** に出る
- 核: 詰まっている感じ。肩・首・背中が固まる。アザ、常時のこり。
- 決定的な違い: 08/11/14と違い「感情や思考より先に、体が反応する」。

**08 💥 イライラ充満** — ストレスが **感情** に出る
- 核: すぐカッとなる。口調がきつくなる。気分の振れ幅が大きい。
- 決定的な違い: 11と違い「考え込まずに出る」。14と違い「動くのではなく、態度に出る」。

**11 🧠 頭ぐるぐる** — ストレスが **思考** に出る
- 核: 同じことを何度も考える。寝る前に頭が回り出す。決めきれない。
- 決定的な違い: 08と違い「表に出さず、内側で回り続ける」。14と違い「動けない」。

**14 🚀 常時アクセル** — ストレスが **行動** に出る
- 核: 止まると落ち着かないので、予定を埋める。頑張りすぎと言われる。
- 決定的な違い: 08と違い「イライラせず、動くことで処理する」。11と違い「考えるより先に動く」。

### めぐり・水分系

**03 🍙 食後スリープ** — **食事に連動して** 重くなる
- 核: 食べた後にがくっと来る。午後が眠い。お腹が重い。
- 決定的な違い: 04と違い「食事という明確なトリガーがある」。食事と関係ない時間帯は平気。

**04 💧 むくみストック** — **食事と無関係に** 溜まる
- 核: 夕方や天気の悪い日に重くなる。水分を溜め込む。
- 決定的な違い: 03と違い「いつ食べたかは関係ない」。天気・時間帯に連動する。

**09 🌸 うるおい不足** — **足りない** 側
- 核: 乾く。肌・髪・唇・目。水を飲んでも足りない感じ。
- 決定的な違い: 03/04と違い「溜まるのではなく、足りない」。06と違い「熱っぽさや寝汗は無い」。10と違い「ふらつきは無い」。

### 温度・リズム系

**05 🧊 冷え冷え** — 熱が **足りない**
- 核: 手足・お腹が冷える。冬が苦手。温まるまで時間がかかる。
- 決定的な違い: 13と違い「朝だけでなく一日中冷えている」。

**06 🔥 ほてほて** — 熱が **こもる**
- 核: 顔や上半身が熱い。寝汗。暑さに弱い。
- 決定的な違い: 09と違い「乾くのではなく、熱い」。12と違い「夜に元気なわけではなく、夜に熱い」。

**12 🌙 夜型スイッチ** — 熱とリズムが **後ろにずれている**
- 核: 夜になると目が冴えて動ける。朝が本調子でない。
- 決定的な違い: 06と違い「ほてりではなくリズムの問題」。13と違い「朝が遅いだけでなく、夜が本番」。

### 複合

**15 🌊 波乗りコンディション** — 2つの系統が拮抗し、かつ本人も変動を自覚している
**16 🎭 クセ強ミックス** — 3つ以上の系統が同時に強く立っている

## 3. 類似タイプとの境界

新設計では、すべての境界が **「同じ系統の中なら識別シグナル1問」「系統が違うなら系統スコアの比較」** のどちらかに単純化される。

| ペア | 同系統か | 何が違えばこちらになるか |
|---|---|---|
| 01 ↔ 02 | 同(エネルギー) | 「休んでも抜けない」→01 / 「常に残量が少ない」→02。**疲労の強さでは分けない**(現行の最大の欠陥を解消)。 |
| 02 ↔ 13 | 同(エネルギー) | 「一日中ずっと低い」→02 / 「朝だけ遅く、動き出せば普通」→13。 |
| 03 ↔ 04 | 同(水分) | 重くなるのが「食後」→03 / 「夕方や天気の悪い日」→04。食事がトリガーかどうかの一点のみ。 |
| 05 ↔ 06 | 同(温度) | 「冷える」→05 / 「熱がこもる」→06。対極なので混ざらない。 |
| 07 ↔ 08 | 同(ストレス) | ストレスが「体」に出る→07 / 「感情」に出る→08。 |
| 08 ↔ 11 | 同(ストレス) | 「感情」に出る→08 / 「思考」に出る→11。表に出るか、内で回るか。 |
| 08 ↔ 14 | 同(ストレス) | 「感情」に出る→08 / 「行動」に出る→14。態度に出るか、動いて処理するか。 |
| 09 ↔ 06 | **異**(水分 vs 温度) | 乾きが主役→09 / 熱が主役→06。**「乾燥」という語をYIN軸から外す**ことで、両方が同時に上がる現象を解消(§8)。 |
| 09 ↔ 12 | **異**(水分 vs 温度) | 乾きが主役→09 / 夜のリズムが主役→12。 |
| 10 ↔ 01/02 | 同(エネルギー) | 「ふらつき・顔色・爪や髪」→10 / 「疲れの抜けなさ」→01,02。 |
| 11 ↔ 14 | 同(ストレス) | 「考え込んで動けない」→11 / 「考える前に動く」→14。 |
| 15 ↔ 16 | — | 2系統が拮抗＋本人も変動を自覚→15 / 3系統以上が同時に強い→16。 |

## 8. うるおい不足・ほてほての分離案

### 方針: 「乾き」は BL のみ、「熱」は YIN のみ に完全分離する

## 9. 8軸＋タイプ固有シグナルの二層構造案

### 現在の構造(問題)

```
30問 → 8軸スコア → 16タイプ
                    ↑ 重なることが前提の軸を、排他的なタイプに直接マッピング
```

### 提案する構造

```
30問 ─┬→ [層1] 8軸スコア ──→ 4軸メーター表示・東洋医学的な裏づけ文
      │           │
      │           └──→ 系統スコア(4つ) ──┐
      │                                    ├→ 16タイプ
      └→ [層2] タイプ固有シグナル ────────┘
              (NEW-A / NEW-B / NEW-C / NEW-D / Q26)
```

**層1(8軸)の役割**: 4軸メーターの表示と、結果ページの東洋医学的な裏づけ。そして「どの系統か」の判定まで。8軸が得意なのは「どのテーマが主役か」であり、そこまでは信頼する。

**層2(シグナル)の役割**: 系統の中でどのタイプかを決める。8軸が苦手な「同じテーマの中の種類の違い」は、専用設問1問で直接聞く。

### 系統スコア

| 系統 | 定義 |
|---|---|
| energy | `QI` |
| stress | `max(ST, STA)` |
| moisture | `max(SP, DAM, BL)` |
| temperature | `max(YANG, YIN)` |

### 判定アルゴリズム

```
1. 8軸スコアを算出する (層1)
2. 系統スコア4つを算出し、降順に並べる
3. [16 クセ強ミックス] 上位3系統がすべて閾値以上 → 16 で確定
4. [15 波乗り]  上位2系統の差が小さい かつ Q26で変動を自己申告 → 15 で確定
5. 最上位の系統を採用する
6. その系統の識別シグナル設問の回答で、タイプを確定する
7. シグナルが「特にない(D)」の場合のみ、系統内の副軸の大小で確定する
```

### この構造が解決すること

| 現在の欠陥 | 解決 |
|---|---|
| ① 特徴を強く出すほど弾かれる | 軸の引き算(`SP>=QI-12`)を全廃。系統内の分岐は識別シグナルのみ。軸は単調に効く。 |
| ② 自然な回答が他タイプの除外条件を踏む | 除外条件(`Q29≠C`, `Q16≠B`)を全廃。同じ系統に入った時点で、他系統のシグナルは参照しない。 |
| ③ 「〜でないこと」で定義されたタイプ | 全16タイプが肯定的な識別シグナルを持つ。イライラ充満=NEW-B:B、電池切れ=NEW-A:C。 |
| ④ クセ強ミックスの名前と実装が逆 | 「3系統以上が同時に強い人」に再定義。名前通りの意味になる。 |
| 判定失敗の受け皿 | **ステップ7により誰も落ちない。** 必ず最上位系統のいずれかのタイプに着地する。 |
| Q2への過剰依存 | Q2はSP軸4問のうちの1問に降格。タイプ識別はNEW-Cが担う。 |

## 11. 16タイプの独立性を高めるためのスコアリング修正案

どちらも「判定できなかった人」ではなく、**その回答パターンでなければ到達できない肯定的な条件**になる。

- 15になる人: エネルギー系と温度系が拮抗していて、本人も「日によってけっこう違う」と答えている人。結果ページで「体調のベースが日替わりで入れ替わるタイプ」と書かれて納得できる。
- 16になる人: 疲れもストレスもむくみも同時に強い人。ブラインドテストで16用に作った回答(寒がりなのにほてる、こりもむくみも乾燥もある)が、まさにこれに該当する。「一言でまとめられない」ではなく「**全部ある**」と書けるので、"失敗"感が出ない。
