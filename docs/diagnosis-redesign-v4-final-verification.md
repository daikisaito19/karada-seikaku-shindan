## 1. 食後スリープの過剰判定を検証

### 1-1. 結論: Q2だけで決まる、は言い過ぎだが「Q2への依存が強すぎる」は正しい

食後スリープのgateは `SP>=35 && DAM>=30 && Q2∈{B,C}` の3条件。個別に見ると：

| 検証 | 結果 |
|---|---|
| Q2="B"固定、残り29問ランダム(N=10000) | 食後スリープ **34.3%** に着地 |
| Q2="C"固定、残り29問ランダム(N=10000) | 食後スリープ **46.3%** に着地 |
| Q2="A"固定(SP/DAM寄与ゼロ)、残り29問ランダム | 食後スリープ **0%**(gateにQ2必須条件があるため理論通り) |
| 完全ランダム(参考) | 食後スリープ **20.6%** |

→ Q2が"B"か"C"であることは **必須条件として機能している**(Q2以外をどれだけSP/DAM最大化方向に振っても、Q2がA/Dならgateは絶対に通らないことを個別テストで確認済み)。「Q2さえ答えればそれだけで決まる」という意味では誤り。

### 1-2. しかし「SP/DAM閾値」がほぼ無風になっている

問題の本質はここ。

```
SP>=35 && DAM>=30 を、Q2を完全ランダムにした状態で満たす割合: 57.6%
Q2がB/Cだった人に限ると、SP>=35 && DAM>=30 も満たす割合: 75.6%
```

つまり **軸条件(SP/DAM)はランダム回答の半分以上が普通に満たしてしまう、ほぼ無風の条件になっている**。理由はSP軸・DAM軸それぞれの最大値(AXIS_MAX)が低く、寄与する設問数が多いため：

- AXIS_MAX(SP)=17、寄与設問9個(Q2,3,4,7,12,13,14,18,30) → 1問あたりの寄与率が5.9〜17.6%に分散していて、3〜4問当たれば余裕で35%を超える
- AXIS_MAX(DAM)=24、寄与設問10個(Q2,3,4,7,13,14,18,20,27,30) → 同様

その結果、食後スリープの出現率(20.09%、Q2のCramér's V=0.354)は、実質的に **「Q2でB/Cを選ぶ確率(50%)」×「その後SP/DAM閾値を満たす確率(75.6%…ほぼ自動的に満たされる)」** でほぼ説明がついてしまう。これは「Q2に人生を握られている」という感覚的な指摘の通り。

### 1-3. 修正の方向性(今回は未実装・提案のみ)

以下のいずれか(または組み合わせ)が候補。実装時にA/Bどちらを取るかは要相談。

- **A案**: SP/DAM閾値を引き上げる(例: SP>=45, DAM>=40)。ただしAXIS_MAXが小さい軸なので、上げすぎるとQ2=B/Cの人でも届かなくなり、今度は「食後スリープなのにクセ強ミックスになる」誤判定が増えるリスクがある → 上げ幅は慎重にシミュレーションで確認する必要あり。
- **B案**: gateにQ2以外の行動シグナルをもう1つ追加する(例: Q12「食事時間がバラバラ/抜く」やQ13「食べると重い」のいずれかを必須にする)。これなら「食後に眠くなる」+「もう一つ食絡みの兆候がある」の2点セットになり、Q2単独の支配力が下がる。
- **C案**: SP/DAMのAXIS_MAXを広げる(寄与する設問・選択肢を増やす)。ただし30問という制約の中で新設問を割くほどの優先度かは要検討。

個人的にはB案(Q2に加えてもう1問の行動確認を必須化)が、他タイプで既に採用している「軸条件+行動マーカー」の設計パターンと一貫性があり、実装コストも低いと考える。ただし最終判断は実装フェーズで相談したい。

## 2. イライラ充満・常時アクセル・カラダ渋滞・頭ぐるぐるの再検証

### 2-1. 結論: 現在のペルソナ定義とgate設計は、ユーザーが要求する切り分け軸と一致している

ご指摘の「イライラ＝動き続ける人ではなく、ストレスや嫌なことが感情・反応として表に出やすい人」「常時アクセル＝行動が止まらない・予定を詰める・休むのが苦手」という切り分けは、`personas.ts` の既存ナラティブに以下の通り反映済みで、gate設計とも整合している：

| タイプ | ナラティブ(現行) | gateの核 |
|---|---|---|
| イライラ充満 | ストレスが即イライラに出る／身体のコリなどは特にない／感情の起伏が激しい | `ST>=55 && STA<32`(行動マーカー不要=「デフォルトで感情が出るタイプ」) |
| 常時アクセル | 頑張りすぎとよく言われる／予定が詰まるとむしろ燃える／休むのが苦手で常に全開 | `ST>=38 && (Q22="A" or Q23="A")`(行動マーカー必須) |
| カラダ渋滞 | 同じ姿勢が続くと調子が落ちる／肩こり・アザができやすい／血行不良 | `ST>=35 && STA>=32`(STAという別軸が必須) |
| 頭ぐるぐる | 考え始めると止まらない／寝る前にいろいろ考えてしまう | `ST>=38 && Q24="D"`(行動マーカー必須) |

旧・確率的シミュレーション(`simulate.ts`の`biasedPick`、strength=0.75)でイライラ充満のHit率が26.8%と低く出ていたのは、**この確率的手法がQ22/Q23/Q24のような「軸スコアゼロの行動マーカー専用設問」を考慮せずランダムに選んでしまう**ため。実際に「そのタイプの人らしく」意図的に行動マーカーを避けて回答する決め打ちペルソナ(`persona-test.ts`)では、この4タイプすべてHit率100%(1回で的中)。旧数値は「ランダム回答者」の話であり、「本人が自然に回答した場合」の実力を反映していなかった。

### 2-2. 境界の実証データ(単問・複数問フリップ)

理想回答から全30問×全選択肢を総当たりして、実際にどの1問を変えると型が変わるかを検証した(`boundary-map.ts`)。

**イライラ充満の理想回答から:**
- → 常時アクセルへ: `Q22=A` または `Q23=A` のみ(1問)
- → 頭ぐるぐるへ: `Q24=D` のみ(1問)
- → クセ強ミックスへ: Q7/Q9/Q13/Q18/Q23の一部をイライラの反応から外す(=ST自体を下げる)と脱落

**カラダ渋滞の理想回答から:**
- 単問変更では他タイプへ一切越境しない(30問×3択=90通り全数チェックで型維持)。イライラ充満へは3問変更でも届かない(=`pair-distance.ts`で確認、STAを32%未満まで下げるには複数問の変更が必要)。

**常時アクセルの理想回答から:**
- 単問変更では他タイプへ一切越境しない。頭ぐるぐるへは2問(`Q22=B, Q24=D`)で到達。

これは「イライラ充満は行動マーカーが1つ変わるだけで隣接タイプへ動く、感情反応中心の"ゆらぎやすい"性格」「カラダ渋滞・常時アクセルは単問では動かない、芯の強いタイプ」という差になっており、設計意図と実際の挙動が一致していることを確認した。

## 4. 類似タイプの「誤着地」確認(8ペア)

理想回答から最小何問の変更で隣のタイプへ移るかを総当たり探索した(`pair-distance.ts`、3問まで)。

| ペア | A→Bの最小変更 | B→Aの最小変更 | 何が違えばこちらになるか |
|---|---|---|---|
| 01充電下手 ↔ 02電池切れ | 1問(`Q2=A`) | **3問以内では不可** | SPがQIに対してどれだけ低いかで決まる。充電下手は「疲れると同時に胃腸も弱る(SPも低い)」人で、Q2で「かなり眠くなる」等を外すだけでSPが落ち、電池切れ側(SPがQIより明確に低い＝純粋な枯渇)へ倒れる。逆に電池切れの人が充電下手に「戻る」には、意図的にSP系設問を複数選び直す必要があり簡単には起きない＝電池切れは一度そこに着地すると安定した領域。 |
| 02電池切れ ↔ 13スロースタート | 2問(`Q1=C,Q29=C`) | 3問(`Q1=D,Q2=B,Q10=B`) | 決め手はQ29「朝の調子は時間が経つとどう変わる？」。電池切れは「時間が経っても本調子にならない」、スロースタートは「最初はイマイチだけど慣れると普通に動ける」で、ここが唯一かつ明確な分岐点。QI/YANGの量ではなく、回復するかしないかという体感の違いで分ける設計。 |
| 03食後スリープ ↔ 04むくみストック | 3問 / 2問 | 「食後」という時間的トリガーの有無。食後スリープはQ2(食後の眠気)必須、むくみストックはQ27(むくみが慢性的にある)が決め手。食後スリープの人がQ2を外し、代わりにむくみ系の実感(Q3のむくみ選択肢やQ27)を選ぶと2問でむくみストック側に倒れる。 |
| 05冷え冷え ↔ 06ほてほて | 3問 / 3問 | YANG(冷え)とYIN(ほてり)は対の軸のため、双方向とも季節系の設問(Q5冬/Q6夏/Q19汗)を3つまとめて反転させないと越境しない。単問では動かない=最も体質的に対照的で紛れにくいペア。 |
| 07カラダ渋滞 ↔ 08イライラ充満 | **3問以内では不可** | 2問(`Q3=B,Q8=B`) | カラダ渋滞→イライラ充満は非常に遠い(STAを32%未満まで下げるのに3問でも足りない)。イライラ充満→カラダ渋滞は2問(身体のこわばり・アザ系の設問を選び直す)で到達可能。つまり「イライラ充満だと思っていたが、実は身体の詰まりも強い」人はカラダ渋滞側へ寄りやすい非対称な関係。 |
| 09うるおい不足 ↔ 10めぐり不足 | 3問 | **3問以内では不可** | YINとQIのどちらが優勢かで決まる(`YIN>=QI` か `QI>=YIN` か)。うるおい不足→めぐり不足は3問で可能(QI系設問を選び直せば届く)だが、めぐり不足→うるおい不足は3問では届かない=めぐり不足(QI優勢・だるさ中心)は一度そこに定まると動きにくい。 |
| 11頭ぐるぐる ↔ 14常時アクセル | 2問(`Q22=A,Q23=A`) | 2問(`Q22=B,Q24=D`) | 双方向とも行動マーカー2問の入れ替えのみで往復可能=この2タイプは「STが高い」という土台は共有しつつ、「考え込むか(Q24)」「動き続けるか(Q22/23)」という行動面の自己申告だけで綺麗に分岐する設計通りの挙動。 |
| 06ほてほて ↔ 12夜型スイッチ | 1問(`Q16=B`) | 1問(`Q16=A`) | 完全にQ16(朝夜どちらが元気か)1問で決まる。設計通りの、意図的に単純化した境界。 |

**全体所見**: 8ペア中、単問(1フリップ)で相互に行き来できるのは06↔12のみ(意図的な単純設計)。11↔14も2問で相互移動でき、これも意図通り(行動マーカーの入れ替えのみで分岐)。それ以外のペアは3問以上、あるいは一方向は3問以内到達不可という「距離のある」関係になっており、隣接ペアが紙一重で頻繁に入れ替わる設計にはなっていないことを確認した。

## 5. クセ強ミックス・波乗りコンディションの役割確認

### 5-1. クセ強ミックス: 「多面的」ではなく「軸は近いが行動マーカーが無い」人が大半

N=20000のランダムシミュレーションで、クセ強ミックスに分類された人(1009人、5.0%)の軸プロファイルを分析：

- 最も高い軸の平均値: 55.8%
- 最高軸が40%以上ある人: **94.2%**
- 最高軸が60%以上ある人: 35.1%

→ 「特に何も突出していない、全部平坦」な人はむしろ少数派。**94.8%は、いずれかのタイプの軸条件に5pt以内まで迫っていた**(`kuse-nearmiss.ts`)。つまりクセ強ミックスの実態は「軸的にはどこかのタイプに近いが、そのタイプが要求する行動マーカー(Q2/Q16/Q22/Q23/Q24/Q26/Q27/Q29など)には該当しなかった人」が大半を占めている。

これは「判定に失敗した人の寄せ集め」ではなく、**「軸の傾向だけでなく、実際の行動・自己申告が伴って初めてそのタイプと認める」という設計の副産物として、意図通り機能している**とも言えるが、一方で「クセ強ミックス=多面的で一言でまとめきれない」という現在のコピーの説明とは、実態がややズレている。「近いタイプはあったが、決め手となる行動の自己申告が無かったので断定を避けた」という性質の方が実態に近い。

**提案(未実装)**: クセ強ミックスの結果コピーを「特徴が拮抗して1つに絞れない」ではなく、「複数の傾向を併せ持っていて、どれか一つと言い切れない」のようなニュアンスに寄せるか、または近接タイプ名を結果画面で軽く示唆する(例:「充電下手や食後スリープの気配もあり」)ことで、"失敗"感を減らせる可能性がある。これはコピー修正のみで済むため、実装フェーズで検討したい。

### 5-2. 波乗りコンディション: 自己申告(Q26)と連動していることを確認

N=20000中1956人(9.8%)が波乗りコンディションに着地。

- Q26で「日によって違う/天候に左右される/前触れなく変わる」を選んでいた人: **92.4%**
- Q26で「安定している」と答えたのに波乗りになった人: 7.6%(僅差＋低い上限値の条件を満たした少数ケース。意図通りの安全弁的な動作)

→ 「複数軸がたまたま近いだけ」ではなく、**9割以上が実際に自己申告と一致した上で拮抗判定になっている**ことを確認。

拮抗していたタイプの組み合わせ(上位)は特定の1パターンに偏っておらず、多様な組み合わせが観測された:

| 拮抗ペア | 割合 |
|---|---|
| 冷え冷え × めぐり不足 | 7.5% |
| ほてほて × うるおい不足 | 7.3% |
| 頭ぐるぐる × 常時アクセル | 5.8% |
| 食後スリープ × うるおい不足 | 5.2% |
| めぐり不足 × 食後スリープ | 4.8% |

→ 「いつも同じ2タイプ同士が拮抗して波乗りに逃げている」という偏りは見られず、体質の異なる複数のペアで発生している。「診断として意味のある結果」と言える状態にあると判断する。

## 6. 質問の自然さ再確認

全30問を通しで読み、重複感・不自然さ・東洋医学的すぎる表現がないかを再チェックした。

### 6-1. 重複感がある設問

- **Q3「長時間、同じ姿勢でいると」× Q9「肩・首こり」の選択肢C「長時間同じ姿勢で凝る」**: Q9の選択肢Cが、Q3の設問文とほぼ同じ言葉(「長時間同じ姿勢」)を使っている。2問連続で「同じ姿勢」というキーワードに触れる形になり、やや答えが読めてしまう。ただしQ3は「体のこわばり・むくみ・眠気」の分岐、Q9は「凝りの原因(ストレス性か姿勢性か常時か)」の分岐で、測定内容自体は別物。表現だけ言い換えれば解消できる軽微な指摘。
- **Q7「ストレスが溜まると」× Q8「嫌なことがあると」× Q23「予定が詰まると」**: いずれも「負荷がかかったときどう反応するか」という同じ型の設問。選択肢の中身(Q7: 寝る/食べる/イライラ/考える、Q8: 忘れる/引きずる/話す/溜める、Q23: 燃える/疲れる/イライラ/逃げる)は重複しておらず、測っている軸(Q7,Q23はST寄り、Q8はST/STA)も違うため致命的ではないが、3問とも冒頭が「〜すると」で始まる同型の設問文になっており、連続して読むとやや単調に感じられる可能性がある。

### 6-2. 答えが予想できてしまう設問

- **Q22「頑張りすぎと言われる」**: 「よく言われる/ときどき/あまり/もっと休んだらと言われる」という4択だが、これ単体で見ると「頑張り屋かどうか」を直接聞いているため、常時アクセルを狙って回答する人が意図的に選びやすい。行動マーカーとして機能させる設計上は妥当だが、質問としての「診断されている感」はやや強め。

### 6-3. 選択肢の並び順の懸念(v3から継続)

- **Q22/Q23**: 常時アクセルの行動マーカーが両方とも選択肢「A」(先頭)に配置されている。オプション順が回答に影響する一般的な傾向(先頭選択バイアス)を考えると、実際のユーザーテストで常時アクセルが理論値より多く出る可能性がある。実装時に、Aを他の選択肢と入れ替える(例:「よく言われる」をC等に動かす)ことを推奨する。

### 6-4. 東洋医学的すぎる表現・意味が分かりにくい設問

該当なし。30問すべて日常会話のレベルの表現で構成されており、専門用語は使われていないことを再確認した。

### 6-5. 結論

致命的な重複や不自然な設問は見つからなかった。Q3/Q9の表現重複とQ22/Q23の選択肢順は、実装フェーズでの軽微な修正候補として記録するに留める(設問構成・スコアリング自体の変更は不要)。
