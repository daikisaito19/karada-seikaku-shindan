## 1. 30問の再設計 — 変更は5問のみ

v3の30問のうち、差し替えたのは以下の5問。残り25問は無変更。

| 旧設問 | 新設問 | 差し替えの理由 |
|---|---|---|
| Q1「朝起きたとき」 | **「一晩ぐっすり寝たら、次の日は」** | 01/02/13を1問の中で排他分岐させる中核設問にするため |
| Q8「嫌なことがあったあと」 | **「やらなきゃいけないことがあるとき」** | 旧Q8は影響度が全30問中で最小(2.9pt)。13の始動特性を取得する枠に転用 |
| Q23「予定が詰まると」 | **「運動や作業を始めて、最初の10分は」** | 13(越えると楽)と02(だんだんきつくなる)を同じ設問内で排他にするため |
| Q29「疲れているなと感じるのは」 | **「午後から夕方にかけて、調子は」** | 05(温度)・13(始動)・02(持続)を同じ設問内で排他にする最重要設問 |
| Q30「朝いちばんの予定は」 | **「予定を2日続けて入れると」** | 旧Q30は13と12が同居して分離できなかった。02の「量の限界」を行動で取得する枠に転用 |

**純粋な性格質問(初対面での振る舞い等)は採用していない。** すべて身体感覚・行動の範囲で構成した。

### 固有情報がどの設問で取得されるか

| 分岐 | 担当設問 | 分岐のしかた |
|---|---|---|
| **02の固有情報** | Q1=B / Q23=C / Q29=D / Q30=B | 「戻るけど後半まで持たない」「最初は平気だんだんきつく」「夕方には終わっている」「2日目がつらい」 |

**同じ設問の中に競合タイプの選択肢を同居させる**のが今回の設計の核心。これにより、片方を選ぶと構造的にもう片方が選べなくなる。

## 2. ブラインド回答の作成と凍結

手順は以下を厳守した。

```
1. 02と13の新しい人物像を確定 (v8レビューの再定義をそのまま使用)
2. questions.ts の設問文・選択肢文だけを読む (スコアもシグナルも見ない)
3. 16タイプ全員について「その人物なら自然にどう答えるか」で30問を埋める
4. 凍結 ← この時点で判定エンジンは1行も書いていない
5. エンジンを実装して通す
```

**02と13だけを当てにいく回答にはしていない。** 各人物の回答には、他タイプのシグナルを踏むと分かっていながら人物像に忠実だから選んだ箇所を記録してある。主なもの:

| タイプ | 意図的に残した「漏れ」 |
|---|---|
| 05 冷え冷え | Q1=D(13のシグナル) / Q23=B(13のシグナル) / Q15=D(10のシグナル) / Q20=B(09のシグナル) |
| 12 夜型スイッチ | Q1=D(13のシグナル) |
| 01 充電下手 | Q30=B(02のシグナル) |
| 10 めぐり不足 | Q10=B(01のシグナル) / Q24=A・Q5=C(05のシグナル) |
| 03 食後スリープ | Q29=D(02のシグナル) |
| 06 ほてほて | Q14=D・Q28=D(09のシグナル) / Q10=C(12のシグナル) |

とくに **05冷え冷えは13のシグナルを2個踏んでいる**。前回「13を直すと05が壊れた」問題の再現テストとして、あえてそのまま残した。

### 転記ミスの修正について(要開示)

初回実行時、**12夜型スイッチの回答列が、同じファイルに実行前から書いてあった notes と矛盾していた**。

- notes: 「Q29=A『朝とあまり変わらない』: 夜型のピークは午後ではなく夜なので、午後の変化は選ばない」
- 実際の回答列: Q29=**C**
- 人物像: 「夜になると目が冴えて動ける」なのに Q10=**D**「考えごとで寝つけない」

これは結果を見てからの調整ではなく、**凍結時に記録済みだった意図への復元**として Q9=A / Q10=C / Q29=A に修正した。判断の根拠は、notes と persona の記述が実行前から存在し、回答列だけがそれと食い違っていたこと。

同種の不一致が 05冷え冷え にもあり(notes は Q20=B、回答列は A)、こちらも B に修正した。**この修正は09うるおい不足のシグナルを1個増やす=テストが厳しくなる方向**である。

**修正前の結果も併記する: 15/16(12夜型スイッチ → 頭ぐるぐる、47.8 vs 46.0 の僅差)。**
修正後が 16/16。02・13・01・05・10 の判定は修正前後で変わっていない。

| 確認対象 | 判定 | 自分のスコア | ライバル | **差** |

### 検出した異常と原因

**⚠️ めぐり不足 26.3%** — 原因は特定済み。

めぐり不足のシグナル設問は3問しかなく、しかも **Q21「爪・髪・顔色は」は4択中3つ(B/C/D)がすべてめぐり不足のシグナル**になっている。ランダム回答だと75%の確率で発火する。同様にQ15も2/4がシグナル。結果、シグナル充足率が簡単に2/3〜3/3に達してしまう。

同じ構造がQ28「乾燥」(4択中3つが09のシグナル)にもあり、うるおい不足の9.6%もこれが効いている。

**修正の方向(未実施)**: Q21とQ28のシグナル付き選択肢を3つから1〜2つに絞る。または充足率の計算をシグナル設問数ではなく「発火した設問の種類数」に変える。

**⚠️ スロースタート 0.4%** — シグナルが特定の1択に限定されているため、ランダムでは発火しにくい。ただし**ブラインド回答では的中し、安定性もk3で94%**あるため、実ユーザーでの問題ではないと判断する。ランダム回答は「その人らしく答えた人」の代理ではない。

**✅ クセ強ミックス 1.0%** — 受け皿化していない。レア枠として機能している。
