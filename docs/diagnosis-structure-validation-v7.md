## ① v6構造の問題点 — ご懸念は正しかった

「NEW-A〜Dの4問だけでタイプが決まってしまうのではないか」を直接測った。

**測り方**: ブラインド回答から、識別4問(Q7/Q22/Q24/Q29)だけをランダムに置き換え、残り26問は固定する。型が変わらなければ「4問に依存していない」ことになる。

| 方式 | 識別4問を変えても型が変わらない率 | 解釈 |
|---|---|---|
| **案A** (v6提案: 系統内を1問で決める) | **34.4%** | **65.6%の確率で型が変わる = 4問で決まっている** |
| 案B (複数シグナルの一致数で決める) | 87.1% | 4問依存は弱い |
| 案C (軸スコア＋シグナルの合算) | 89.1% | 4問依存は弱い |

逆方向も測った(識別4問だけ固定して残り26問をランダム化 → 型が維持される率)。案Aは22.8%、案Bは12.9%、案Cは14.1%。**案Aだけが両方向で「4問の影響が突出している」**。

**結論: v6のD章で提案した案A(系統識別シグナル1問方式)は、そのまま採用すべきではない。** 30問答えた意味が4問に集約されてしまう。ご指摘の通りだった。

### 各タイプが「4問だけ」でどの程度決まるか (案A)

識別4問を固定して残り26問をランダム化したとき、意図した型が維持される率:

| タイプ | 維持率 | | タイプ | 維持率 |
|---|---|---|---|---|
| 01 充電下手 | 33% | | 03 食後スリープ | 16% |
| 02 電池切れ | 31% | | 04 むくみストック | 16% |
| 13 スロースタート | 17% | | 09 うるおい不足 | 20% |
| 10 めぐり不足 | 29% | | 05 冷え冷え | 19% |
| 07 カラダ渋滞 | 30% | | 06 ほてほて | 13% |
| 08 イライラ充満 | 29% | | 12 夜型スイッチ | 23% |
| 11 頭ぐるぐる | 24% | | 14 常時アクセル | 19% |

## ④ 1問1軸 vs 主軸＋副軸

ご指摘の通り、「設問の意味として複数軸に関係すること」と「スコア上、複数軸に強く加点すること」は別物だった。同じ設問セット・同じ判定ロジックで、スコアリング方式だけを変えて比較した。

| スコアリング方式 | 案A | 案B | 案C |
|---|---|---|---|
| 方式1: 1問＝1軸(主軸のみ) | 14/16 | 13/16 | 14/16 |
| 方式2: 主軸＋副軸(同じ重み) | 14/16 | 13/16 | 14/16 |
| 方式3: 主軸＋副軸(副軸は半分の重み) | 14/16 | 13/16 | 14/16 |

**3方式で的中率が1件も変わらなかった。**

### この結果の意味

**タイプ判定の精度は、副軸の扱いにほとんど影響されない。** 判定を動かしているのは主軸とシグナルであり、副軸は「どちらでもいい」レベルの影響しか持たない。

したがって「1問1軸を原則化すべきか」は、**判定精度の問題ではなく、別の2つの観点で決めるべき**:

| 観点 | 判断 |
|---|---|
| **設問の重複管理** | 副軸が増えるほど設問同士の軸ベクトルが似てくる(現行30問で類似度0.7以上が36組あった原因)。**方式1か方式3が望ましい** |
| **4軸メーターの自然さ** | 「食後に眠い」がSPにしか効かないと、エネルギーメーターが動かず体感とズレる。**副軸はあったほうが自然** |

### 結論: 方式3(主軸＋副軸を弱く)を推奨

理由は精度ではなく、**メーター表示の自然さを保ちつつ、設問の構造的重複を防げるから**。
運用ルールとして:
- 主軸は必ず1つだけ。強く加点する。
- 副軸は最大1つ。主軸の半分の重みまで。
- 副軸だけを持つ選択肢は作らない(どの軸に属する設問か不明瞭になるため)。

「食後に眠い」= SP(主) + QI(副・半分)、のように**意味上の関係は残しつつ、判定は主軸が担う**形になる。

### 「東洋医学として正しいか」ではなく「体験として意味があるか」

ご指摘の通り、9軸化を「診断学として正確になる」とは考えていない。実際、陰虚は本来「乾き」と「内熱」を同時に含む概念であり、それを2つに割るのは東洋医学的には不正確である。

採用する理由は**ユーザー体験の側にある**:

1. **4軸メーターが正確になる**。現状は「うるおい」メーターが BL と YIN から計算されており、ほてりやすい人のうるおいメーターが下がる。JIN導入後は `うるおい = 100 − 平均(BL, JIN)`、`温度 = 50 + (YIN − YANG)/2` となり、**熱の要素が温度メーターだけに寄る**。体感と表示が一致する。
2. **結果ページの説明文が書き分けられる**。「乾いている」と「こもっている」を別の言葉で書けるようになる。

逆に言えば、**この2つの利点が得られないなら9軸化する必要はない**。裏側の東洋医学的な説明文では「陰虚(乾きと熱)」として1つに戻して記述しても問題ない。

## ⑥ 16タイプの名前と中身

### めぐり不足 — 改名候補

中心概念を「血・栄養・材料の不足」に確定させると、「めぐり(=循環)」という語とズレる。循環の停滞は07カラダ渋滞の担当であり、**2タイプが「めぐり」という言葉を取り合う**状態になる。

医療っぽさを避けた候補:

| 候補 | ニュアンス | 評価 |
|---|---|---|
| **ガス欠ぎみ** | 燃料が尽きかけている。車の比喩で分かりやすい | 「電池切れ」と比喩の系統(エネルギー枯渇)が被る。**02と紛らわしい** |
| **燃料不足** | 同上 | 同上の理由で02と被る |
| **補給待ち** | 足りないものを入れれば戻る、という回復可能性が出る | 02と比喩が被らず、「材料不足」の意味に近い。**有力** |
| **カラダ燃費わるめ** | 同じ量で足りなくなる | 面白いが、意味が「消費が早い」になり材料不足とズレる |
| **血色フェードぎみ** | 顔色・爪・髪という見た目の症状に寄せる | 症状は的確だが「血色」がやや医療寄り |
| **エネルギー届かない系** | 供給の問題であることが直接伝わる | 説明的すぎて名前として弱い |
| めぐり不足(現状維持) | — | キャッチコピー「流れてはいる。運ぶ中身が足りない」で誤読を防ぐ前提なら可 |

**推奨は「補給待ち」**。理由は、(1)02電池切れと比喩が競合しない、(2)「入れれば戻る」という回復可能性が名前に含まれ、結果を読んだ本人が前向きに受け取れる、(3)医療用語を一切含まない。

ただし16タイプの名前の統一感(◯◯不足 / ◯◯ミックス / ◯◯スイッチ など)を崩す可能性があるため、**最終判断はお任せしたい**。

### クセ強ミックス — 「3系統以上が強い」は面白い結果になるか

まず出現率を測った。閾値を変えたときのランダム回答での出現率:

| クセ強の閾値 | 出現率 | ブラインド的中 |
|---|---|---|
| 55% (v6案) | **32.6%** | 14/16 |
| 60% | 10.9% | 14/16 |
| 65% | 5.1% | 14/16 |
| **70%** | **1.3%** | 14/16 |
| 75% | 0.5% | 14/16 |
| 80% | 0.0% | 13/16 |

**v6で提案した55%のままだと、ランダム回答の3人に1人がクセ強ミックスになる。** これは「受け皿化」の再来であり、そのまま採用すると v6 で批判した状態に逆戻りする。**70%が適切**(出現率1.3%、的中率は落ちない)。

その上で「面白い結果になるか」の検討:

| 読まれ方 | 成立する条件 |
|---|---|
| **ポジティブ(レア枠)**: 「16人に1人どころか、100人に1人。全部持ってる」 | 出現率が**十分に低い**こと。1.3%なら「レアを引いた」感覚になり、共有したくなる |
| **ネガティブ(判定失敗)**: 「どれにも当てはまらなかった人」 | 出現率が高いと必ずこう読まれる。55%閾値(32.6%)では確実にこうなる |

**結論: 閾値70%(出現率1.3%)なら、レア枠としてポジティブに成立する。** ただし結果ページの書き方が決定的に重要で、「一言でまとめられない」ではなく「**全部ある。100人に1人のフルコース**」のように、**希少性を前面に出す**必要がある。

名前については、「クセ強」という語は近年の日本語では肯定的・愛好的なニュアンス(「クセが強いけど面白い」)で使われることが多く、**出現率さえ低ければ名前を変える必要はない**と考える。

## ⑦ 波乗りコンディションの再設計

### v6案の問題

v6では「上位2系統が僅差 かつ Q26で自己申告」という条件だった。ご指摘の通り、**「スコアが近い」と「日によって変わる」は別の概念**であり、前者を条件に入れること自体が間違っていた。

### 新設計: スコアの近さを一切使わない

**変動を示す回答の個数だけで判定する。**

変動シグナルを4問に分散して配置した:

| 設問 | 変動シグナルになる選択肢 |
|---|---|
| Q16 朝と夜、元気なのは | D「日によって違う」 |
| Q18 天気が悪い日は | D「天気で調子が決まってしまう」 |
| Q20 肌は | D「季節や日によって大きく変わる」 |
| Q26 体調の波は | B「日によってけっこう違う」/ C「天気や気圧に左右される」/ D「前ぶれなく急に変わる」 |

判定: **このうち3個以上を選んだら波乗りコンディション。** 軸スコアも系統も一切参照しない。

### 閾値の検証

| 変動シグナル | 出現率 | ブラインド的中 |
|---|---|---|
| 2個以上 | 45.9% | 12/16 |
| **3個以上** | **11.8%** | **14/16** |
| 4個以上 | 1.0% | 14/16 |

3個以上が適切。4個以上だと厳しすぎて「本当に波がある人」も取りこぼす(30問中4問すべてで変動を選ぶ必要がある)。

### 検証結果

- ブラインド回答(変動を4つ選んだ人物像)で**正しく波乗りと判定された**
- 安定性 k3 = 98〜99%(全タイプ中で最も安定)
- 決定打: Q20=D(+15.8pt) / Q16=D(+15.3pt) / Q18=D(+15.2pt) — **3問が均等に効いており、1問依存になっていない**

**「たまたまスコアが近かった人」は、もう波乗りには入らない。** 入るのは「日によって違う」と4問中3問で自分から答えた人だけ。

## ⑧ クセ強ミックスの再設計

### 失敗の原因 — これはロジックの問題ではない

**02 電池切れ と 13 スロースタート には、自分だけの体感が存在しない。**

| タイプ | 訴える症状 | 同じ症状を訴える他タイプ |
|---|---|---|
| **02 電池切れ** | 常にだるい / 顔色が悪い / 立ちくらみ / 少し動くと息切れ | **10 めぐり不足**(顔色・立ちくらみ)、**01 充電下手**(だるさ) |
| **13 スロースタート** | 朝が重い / 布団から出られない / 午前中は使いものにならない | **05 冷え冷え**(朝の冷えで動けない)、**12 夜型スイッチ**(朝が本調子でない) |

ブラインド回答を作った時点で、私は「02の人なら Q21=D 顔色が悪い を選ぶだろう」と書いた。これは人物像に忠実な回答だが、同時に **10めぐり不足のシグナルでもある**。13も同様で、「朝が重い」は冷え性の人も夜型の人も選ぶ。

これを裏づける実験を2つ行った:

1. **5系統版(案C')を作り、13を独立系統にした** → 13は的中するようになったが、今度は**05冷え冷えが13に吸い込まれた**(冷え性の人も「朝、動き出すまで」と答えるため)。問題が移動しただけ。
2. **設問を2問修正した**(Q3を「午後から夕方の変化」に差し替え、Q17に02専用の「少し動くと息切れ」を追加) → 13の単調性は 31%→44%→39%→0% と改善せず、02は今度はめぐり不足に吸われた。

**つまり、判定ロジックをどう変えても、設問を足しても、この2タイプは解けなかった。**

### 示唆: これはタイプ構成(ロスター)の問題かもしれない

現時点での率直な見立てとして、以下のいずれかが必要だと考える。

| 選択肢 | 内容 | トレードオフ |
|---|---|---|
| **(a) 02と13に排他的な体感を作る** | 他のどのタイプも選ばない質問を新設する。例: 13なら「午後には完全に元通りになる」を単独で強く効かせる | 設問の追加が必要。「診断されている感」が増す |
| **(b) 02を01に統合し、空いた枠に別タイプを作る** | 「充電下手」と「電池切れ」を1つにまとめ、16枠目に独立性の高い新タイプ(例: 胃腸まわり、頭痛・気圧系など)を入れる | タイプ名が1つ変わる |
| **(c) 13を12夜型と統合して「リズム系」1タイプにする** | 朝が遅い/夜が本番を1タイプに束ねる | 同上 |
| **(d) 14/16でよしとする** | 02と13は「隣接タイプに吸われやすいタイプ」として受け入れる | ご要望の「そのタイプの人が答えたらそのタイプになる」を2タイプで満たせない |

**(a)を試す価値はあるが、今回の設問修正実験では効果が出なかった。** (b)(c)はタイプ構成の変更を伴うため、判断をお願いしたい。

## ⑫ 最終的に採用すべき診断構造案

```
30問
 ├→ [層1] 9軸スコア ──→ 4軸メーター表示 + 東洋医学的な裏づけ文
 │         └→ 系統スコア(4つ) ─┐
 │                               │
 └→ [層2] タイプ固有シグナル ───┤
           (全30問に分散、1タイプあたり3〜6個)
                                 ↓
      ┌──────────────────────────────────────┐
      │ 1. 変動シグナルが3個以上 → 15 波乗り      │ ← 軸を一切見ない
      │ 2. 上位3系統が70%以上   → 16 クセ強      │ ← 出現率1.3%
      │ 3. それ以外 → 主軸% + シグナル数×12 の   │
      │    合算が最大のタイプ (14タイプから選択)  │
      └──────────────────────────────────────┘
                                 ↓
                             16タイプ
```

### v6案からの変更点

| 項目 | v6案 | v7案(今回) | 理由 |
|---|---|---|---|
| 系統内の判定 | 識別シグナル**1問** | **全30問に分散したシグナルの合算** | 案Aは4問依存が66%と判明(①) |
| 系統の使い方 | 系統で絞り込んでから決定 | 系統はクセ強判定にのみ使用 | 系統で絞ると系統をまたぐ衝突(13↔05)を救えない |
| 波乗りの条件 | 上位2系統が僅差 ＋ 自己申告 | **変動シグナル3個以上のみ** | 「スコアが近い」は「波がある」ではない(⑦) |
| クセ強の閾値 | 3系統が55%以上 | **3系統が70%以上** | 55%では出現率32.6%で受け皿化(⑥) |
| スコアリング | 1問1軸を原則化 | **主軸＋副軸(半分の重み)** | 精度に差は無く、メーター表示の自然さで選択(④) |

### 識別シグナル設問(NEW-A〜D)の扱い

**廃止はしない。** ただし役割を変える。

- v6案: 系統内のタイプを**単独で決定する**設問
- v7案: 他の設問と**同じ重み**のシグナル設問の1つ。ただし4択すべてが別々のタイプを指すため、シグナル効率は最も高い

実測でも、Q7(ストレスの出かた)の決定打としての効き方は「頭ぐるぐる +3.8pt」程度で、他の設問(Q8=B +5.1pt など)と同水準に収まっている。**1問で決まる設問は存在しなくなった。**

## 現時点で実装してよいか

### 判断: **まだ実装すべきではない。ただし理由はv6のときと変わった。**

v6の時点では「構造そのものが間違っている」という理由だった。今回の検証で、**構造の問題は解決した**:

- 1問依存 → 解消(4問を変えても89%が同じ結果)
- 単調性の逆転 → 6タイプ相当から1タイプに削減
- 安定性 → k3平均95%(現行45〜99%)
- 波乗り・クセ強の受け皿化 → 解消(積極的条件のみで成立、誤流入0件)
- うるおい不足↔ほてほて、ストレス系3タイプ → 完全分離

残っている問題は1点だけ、しかしそれは構造では解けない:

**02 電池切れ と 13 スロースタート に、自分だけの体感が存在しない。**

5通りの構造(案A/B/C/C'/設問修正版)をすべて試して、いずれも14/16で頭打ちになり、**外れるのは常にこの2タイプだった**。判定ロジックの問題ではなく、16タイプという枠組みの中でこの2つに固有の居場所が無いことが原因である。

### 次に決めていただきたいこと

1. **⑨の(a)〜(d)のどれを採るか** — 02と13の扱い。これが決まれば実装に入れる
   - (a) 02と13に排他的な設問を新設する(今回の修正実験では効果が出なかったため、別の切り口が必要)
   - (b) 02を01に統合し、16枠目に独立性の高い新タイプを作る
   - (c) 13を12夜型と統合して「リズム」1タイプにする
   - (d) 14/16を許容して実装に進む
2. **めぐり不足の改名**(⑥) — 推奨は「補給待ち」だが、16タイプの名前の統一感との兼ね合いで判断が必要
3. **クセ強ミックスの結果コピーの方向性**(⑥) — 「一言でまとめられない」ではなく「100人に1人のフルコース」路線で進めてよいか
4. **案B寄りか案C寄りか**(③) — 判定は案C、根拠表示は案B、というハイブリッドを推奨

1が決まり次第、`src/` への実装に着手できる状態にある。それまでコード変更・コミットは行わない。
