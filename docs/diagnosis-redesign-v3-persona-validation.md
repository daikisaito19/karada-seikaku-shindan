# カラダ性格診断 再設計案 v3 — ペルソナ検証レポート

v2設計案（`diagnosis-redesign-v2.md`）に対して「ランダム分布の均等化」ではなく「そのタイプらしい人が本当にそのタイプになるか」を最優先に据えて再検証した。**このドキュメントの内容もまだ `src/` には反映していない。コミットもしていない。**

検証コードは `scripts/redesign-v2/personas.ts`（16タイプの決め打ち回答）と `scripts/redesign-v2/persona-test.ts`（判定・安定性テスト）。v2からの主な変更点は次の2つ。

- Q26「熱くなるのは」を「体調の波は？」に差し替え、**波乗りコンディションの判定に、初めて専用の設問シグナルを持たせた**（後述⑦）。
- Q22/Q23のデフォルト回答が意図せず常時アクセルの条件を誤爆する不具合を修正（後述・検証中に発見）。

## ⑥ 「クセ強ミックス」の判定条件

**判定条件**：14タイプいずれのゲート条件も満たさない場合のみ。「主軸のしきい値に届かなかった人の寄せ集め」ではなく、**どの軸の組み合わせを見ても、どのタイプの核となる条件（しきい値＋行動シグナル）にも届かない**という、積極的な意味での「特徴が定まらない」状態を指す。

検証：
- ランダム回答60,000件中 **5.25%**（前回設計時点の22%台からは大きく減少。前回値は今回のv2/v3設計以前の初期案での数値）。
- 16タイプの理想回答のうち、クセ強ミックス以外の15タイプがこの判定に紛れ込むことはなかった（③の表で確認済み）。
- 意図的に「どの軸も薄く触れるが、どれも強くしない」回答を作ったところ、狙い通りクセ強ミックスと判定された。

これにより、「何でもかんでもミックスに入るフォールバック」にはなっていないことを確認できた。ただし5.25%という数字自体は、実際のユーザーテストで妥当かどうか改めて検証が必要（本物のユーザーは、いずれかの軸に多少なりとも偏りを持つ回答をする可能性が高く、実際の出現率はこのランダム回答シミュレーションより低くなると予想している）。

## ⑦ 「波乗りコンディション」の判定条件

**旧v2の課題**：v2時点では「複数タイプの候補が僅差」というスコアの近さだけで判定しており、指摘の通り「単純に複数軸が近いだけの人」を拾っていた可能性があった。また「日によって体調が変わる」という体験を直接尋ねる設問が30問の中に1つも無かった。

**v3での変更**：
1. 新設問「体調の波は？」（Q26）を追加した（詳細は⑨⑩）。「日によって、けっこう違う」「前触れなく急に変わる」と答えた人だけ、波乗りコンディションに回るためのスコア上限を引き上げる（55→65）。逆に「安定している」と答えた人は、僅差でもなるべくどちらかのタイプに決め切るよう上限を下げる（55→48）。
2. 判定条件自体は変更していない：**2つ以上のタイプのゲート条件を実際に満たし、かつ上位2タイプのスコア差が6点未満**の場合のみ。「ゲートを満たすタイプが1つもない」状態（クセ強ミックス）とは明確に区別される。

検証：意図的に「カラダ渋滞」と「うるおい不足」の両方の条件を拮抗する強さで満たす回答を作ったところ、狙い通り波乗りコンディションと判定された（③参照）。これは「本当に2つの特徴が同程度に強く、決め手がない」状態を示せている。

ランダム回答での出現率は9.61%（前回6.88%から増加）。これは、Q26の自己申告シグナルによって「本当に波がある」と答えた人がより確実に波乗りコンディションに回るようになった結果であり、意図した方向の変化と判断している。

## ⑧ 30問の重複チェック

現在の30問（v2版）を、指摘のあった観点で再点検した。

| 観点 | 対応する設問 | 評価 |
|---|---|---|
| むくみ | Q3(部分)・Q14・Q18・Q27 | ◎ 4問で多角的にカバー |
| 乾燥 | Q15(部分)・Q20(部分)・Q21・Q28 | ◎ 十分 |
| 冷え | Q1(部分)・Q5・Q14(部分)・Q19(部分)・Q25 | ◎ 十分 |
| ほてり | Q6・Q19(部分)・Q28(部分) | ○ 十分 |
| めぐり(血行) | Q3・Q8(部分)・Q9・Q11 | ◎ 4問でカバー |
| 夜型/朝型 | **Q16のみ** | △ 1問のみ。ただしこれは意図的設計（後述） |
| 思考傾向 | Q7(部分)・Q24 | ○ 十分 |
| 回復 | Q1・Q10 | ○ 十分 |
| 食後 | **Q2のみ** | △ 1問だが、最も強い判別力を持つ設問として機能している |
| 気分の波 | **なし（v2時点）** | ✕ 未対応だった → v3でQ26を新設して対応 |
| ストレス反応の重複感 | Q7・Q8・Q13・Q18・Q23・Q24 | △ 6問と多め。ただし内容は「寝る/食べる/イライラ/考える」等、切り口が異なる |

**「夜型/朝型」「食後」が1問に依存している点について**：これは弱点というより意図的な設計。この2問（Q16・Q22系ではなくQ16とQ2）は、その回答自体が「行動シグナル」としてゲート条件に直接使われる設計にしており、頭ぐるぐる(Q24)・スロースタート(Q29)・常時アクセル(Q22/23)も同様に単一設問への依存を意図的に採用している。これは複数のペルソナ検証で機能することを確認済み（③④）。ただし、**1問への依存はユーザーの気まぐれな回答揺れに弱いというリスクは残る**ため、Q16は特に「1問しかない」ことを許容範囲と見るか、補強するかは今後判断が必要な論点として明記する。

**ストレス反応クラスタ（Q7/Q8/Q13/Q18/Q23/Q24）の6問**は、当初の懸念（Q3/Q11/Q15/Q21が似た角度で疲労を聞いていた問題）とは別物で、いずれも東洋医学でいう「気滞」の異なる現れ方（寝る/食べる/身体で受け止める/気分に出る/予定への反応/思考のループ）を聞き分けている。ただし6問は多めなので、⑨⑩でQ18を再検討する。

## ⑨ 修正が必要な質問

1. **Q22「頑張りすぎと言われる」**：選択肢A（先頭）が常時アクセルの必須シグナルを兼ねているため、回答に迷ったユーザーが先頭選択肢を選ぶ傾向（オーダーバイアス）があると、常時アクセルに偏るリスクがある。対応: プロトタイプでは影響を避けるため検証用の中立デフォルト値を設定したが、実装時は選択肢の順序を見直す（行動シグナルの選択肢を先頭に置かない）ことを推奨する。

## ⑪ 修正後の判定ロジック案

v2のゲート＋スコア方式を維持しつつ、以下を追加した。

```
1. 30問の回答から内部8軸の生スコア → 0-100%に正規化(v2と同じ)
2. 14タイプ each について: gate(軸%, 回答) を判定 → 通った候補のみ matchScore を計算(v2と同じ)
3. 候補が0個 → 16「クセ強ミックス」(v2と同じ)
4. 候補が1個以上:
   a. Q26(体調の波は？)への回答を見る
      - 「日によって違う」「前触れなく変わる」 → nami_nori_ceiling = 65
      - それ以外(安定・天気次第)            → nami_nori_ceiling = 48
   b. トップと2位の差が6点未満 かつ トップのスコアが nami_nori_ceiling 未満
      → 15「波乗りコンディション」
   c. それ以外 → 最高スコアのタイプ
```

v2との違いは4-a・4-bの「波乗りコンディションへの逃げやすさを、ユーザー自身の自己申告で調整する」部分のみ。これにより、波乗りコンディションが「スコアがたまたま近いだけの人」を拾う設計から、「本人が実際に体調の波を感じている」ことと連動する設計に変わった。

## 総括

- 16タイプ全てについて、専用に組んだ理想回答で意図通りに判定されることを確認した（16/16）。
- 安定性は14タイプがk=1で85%以上を維持。波乗りコンディションとイライラ充満はやや揺れやすいが、前者は設計上自然、後者は今後の閾値調整候補として記録した。
- クセ強ミックスは「ゲートに届かなかった人の寄せ集め」ではなく、実際にどの主要な特徴も持たない場合にのみ出現することを確認した（ランダム回答5.25%、理想回答での誤判定なし）。
- 波乗りコンディションに、初めて専用の設問シグナル（Q26）を持たせ、「本当に日々の変動を感じているか」に連動する設計にした。
